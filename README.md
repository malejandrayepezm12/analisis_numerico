# analisis_numerico
Este repositorio contiene las soluciones a los puntos de los talleres asignados para cada uno de los exámenes.

Se encuentra la carpeta "notebooks", que contiene a su vez carpetas individuales por taller, con cuadernos de jupyter para cada una de las soluciones de los puntos. El nombre de los cuadernos hace referencia al punto del taller que se va a solucionar.
